How to use RoboCopier

What it does

RoboCopier keeps a local copy of a folder that lives somewhere else (a network drive, a shared OneDrive, a coworker's folder). Every refresh it checks what changed and copies just the new or updated files. The source folder is never modified.

Adding a task

Click Add task. Give the task a short name (no spaces, like weekly-schedule). Browse to the folder you want to copy FROM. Pick a mode. Optionally set a schedule. Click OK.

Replace vs Archive mode

Replace - local copy always matches the source as of the last refresh. Deletes follow.

Archive - each refresh creates a new dated subfolder with a full snapshot. Old snapshots stay.

Scheduling

Pick Daily / Weekly / Monthly, set the time, click OK. RoboCopier creates a Windows scheduled task that fires the refresh silently. User-scope only - runs when you are logged in.

Where copies are saved

Under your default destination (shown at the top of the main window), each task gets its own subfolder named after the task. Override per-task in the dialog if needed.

Size safeguards

This tool is for individual files and small folders. Over 200 files or 200 MB triggers a warning. Over 2000 files or 2 GB refuses outright.

Refreshing manually

Select tasks and click Refresh selected, or REFRESH ALL for everything.

Auto-updates

RoboCopier checks for new versions on launch and every 30 minutes. New versions download automatically and prompt you to restart.
